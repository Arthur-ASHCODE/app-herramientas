1. Base de datos y conexión
Crear la BD MySQL, archivo de configuración y una clase/conexión PDO. Antes de login necesitamos tener dónde consultar usuarios.

2.Crear tabla usuarios, usuario administrador inicial y hacer que el formulario valide contra la BD, password_hash() y password_verify().

3.Sesiones
Cuando las credenciales sean correctas:
Login → valida usuario → crea $_SESSION → /dashboard

Y proteger:
/dashboard
/modulo01
/modulo02
/modulo03

4. Logout
Destruir sesión y regresar a /login.

5. Datos reales en los módulos
Ahí ya empezar a trabajar en:

Controller -> Model -> MySQL -> Controller -> View -> Tabla -> HTML

y posteriormente CRUD: crear, consultar, editar y eliminar.
